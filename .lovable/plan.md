# دعم Risen 3 (localization.p00) — ترجمة وبناء

## الوضع الحالي

فحصت ملفك فعلياً وحدّدت الصيغة بالكامل:

- الملف = رأس `G3V0` (‏0x30 بايت) + تيار zlib واحد.
- بعد فك الضغط: أرشيف `GAR5` يحوي جدول نصوص `STB v5` فيه **18 جدول CSV** (‏strings, infos, quests, documents, cutscenes, items, hud3, skills…) و**14 عموداً** (`German_Text`, `English_Text`, … `*_StageDir`) و‏~43,900 صف.
- النصوص **ليست UTF-16 صريحة** كما في Risen 1: كل عمود مخزَّن كـ symbol/sequence (سلاسل رموز مترابطة عكسياً لإعادة استخدام المقاطع المكررة). لذلك أدوات Risen 1 الحالية لا تصلح إطلاقاً هنا.
- مفاتيح الصفوف = هاشات 32-بت (DJB2 معدّلة) مرتبة تنازلياً.

المرجع: أداة `lianzifu` مفتوحة المصدر (Risen 3 / ELEX) — سأستخدم توثيق بنيتها ونعيد التنفيذ بـ TypeScript داخل المتصفح (بدون خوادم).

## ما سأبنيه

### 1. محلّل/باني الصيغة (`src/lib/risen3/`)
- `p00-container.ts` — فك/إعادة بناء غلاف `G3V0` + zlib + `GAR5`.
- `stb-parser.ts` — قراءة رأس STB، جدول المصادر (مسارات CSV)، أسماء الأعمدة، هاشات الصفوف، وفك سلاسل الرموز إلى نصوص (مع حد سلسلة 33 حرفاً).
- `stb-writer.ts` — إعادة البناء: كتابة جدول رموز جديد يدعم **العربية (UTF-16)**، مع إبقاء ترتيب الصفوف والهاشات والأعمدة الأخرى كما هي بايت-ببايت.
- `risen3-categories.ts` — تصنيف المدخلات حسب ملف CSV الأصلي (حوارات، مهام، وثائق، أغراض، واجهة…).

### 2. صفحات الواجهة
- `/risen3` — صفحة تعريف بالأداة (بنفس أسلوب صفحة Risen 1).
- `/risen3/process` — رفع `localization.p00`، عرض تقرير المحتوى، ثم الانتقال للمحرر.
- زر «بناء الملف» يُنتج `localization.p00` جاهزاً للعبة.

### 3. ربط المحرر
- إضافة نوع لعبة `risen3` (مثل `risen`/`risen2`) في كشف نوع اللعبة، الفلاتر، وشريط التقدّم.
- عرض عمود `English_Text` كمصدر مع رجوع تلقائي للألماني عند الفراغ (نفس منطق Risen 1)، والكتابة في `English_Text` عند البناء.
- استخدام حارس شخصية Risen نفسه في دوال الذكاء الاصطناعي (منع تسرّب مصطلحات Xenoblade) + قناع الوسوم `<...>` و `$(...)`.

### 4. اختبارات
- `risen3-stb-roundtrip.test.ts`: فك ثم إعادة بناء بدون تعديل ⇒ يجب أن ينتج جدول نصوص مكافئ (نفس عدد الصفوف/الهاشات ونفس النصوص عند إعادة القراءة).
- اختبار حقن نص عربي وقراءته مجدداً.

## ملاحظة مهمة (خارج نطاق هذه المرحلة)
مثل Risen 1: المحرك لن يعرض الحروف العربية حتى يُستبدل خط اللعبة. هذه المرحلة تُنتج ملف نصوص صحيحاً فقط. أداة الخطوط لـ Risen 3 مرحلة لاحقة منفصلة.

## تفاصيل تقنية

رأس STB (‏9 × u32): magic (`'S','T','B',version≥5`)، عدد المصادر، محجوز، عدد الأعمدة، عدد الصفوف، إزاحة جدول المصادر، إزاحة أسماء الأعمدة، إزاحة جدول الأعمدة، إزاحة جدول المفاتيح.

كل عمود = زوج `{size,pos}` لمنطقتين:
- `str_tab`: `u32 str_beg[row_count]` (‏`0xFFFFFFFF` = نص فارغ) + تيار `u16` من فهارس الرموز ينتهي كل نص بـ `0`.
- `sym_tab`: `u32[]` حيث الـ 16 بت العليا = حرف UTF-16 والـ 16 بت السفلى = فهرس الرمز السابق في السلسلة (‏0 = النهاية).

عند البناء سأستخدم أبسط استراتيجية آمنة (`pack none`): سلسلة رموز مباشرة لكل نص مقسّمة إلى مقاطع ≤33 حرفاً — أكبر حجماً قليلاً لكن zlib الخارجي يعوّض، والمحرك يقرأها بنفس المنطق.
